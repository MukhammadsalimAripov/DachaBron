# Dacha Bron (Дача Брон) — Сервис бронирования дач на Next.js

Современное веб-приложение на **Next.js (App Router)** для онлайн-бронирования горных вилл, коттеджей и дач в Ташкентской области (Чарвак, Чимган, Бричмулла, Бочка, Хумсан, Юсуфхона) с работающим **AI-помощником** и панелью администратора.

---

## 🌟 Ключевые возможности

### 1. Навигация (Navbar)
- 5 основных страниц:
  1. **Главная (`/`)**
  2. **Дачи (`/catalog`)** — при наведении (hover) плавно открывается выпадающее мини-окно со ссылками:
     - *Все дачи* (`/catalog?cat=all`)
     - *Виллы* (`/catalog?cat=villa`)
     - *Большие дачи* (`/catalog?cat=bolshiye`)
     - *Средние дачи* (`/catalog?cat=sredniye`)
     - *Маленькие дачи* (`/catalog?cat=malenkiye`)
  3. **О нас (`/about`)**
  4. **Отзывы (`/reviews`)**
  5. **Контакты (`/contacts`)**
- Переключатель тем:
  - **Светлая тема (Light Mode)**: синий и белый стиль (`#2563eb` и `#ffffff`).
  - **Темная тема (Dark Mode)**: строгий черно-белый стиль (`#000000` и `#ffffff`).
- Переключатель языков: **Русский (RU)**, **Узбекский (UZ)**, **Английский (EN)**.
- Авторизация / Профиль пользователя (Войти / Регистрация / Выйти).
- **Админки в навигации нет!** (кнопка доступа находится только в футере).
- **Страницы оформления заказа в навигации нет!**

---

### 2. Главная страница и работающий AI-помощник
- В верхней части страницы размещен **AI Помощник**:
  - Принимает запросы на естественном языке (например: *"Найди виллу на Чарваке с теплым бассейном на 10 человек до $600"*).
  - Быстрые подсказки: *"🏰 Роскошная вилла с бассейном"*, *"🏕️ Уютный A-Frame для двоих"*, *"🎉 Большая дача на 20 человек"*.
  - Фильтры: количество гостей, локация, бегунок бюджета ($ в сутки), главное удобство (бассейн, сауна, бильярд, камин, BBQ).
  - **Реальный обработчик `/api/ai`**: анализирует параметры, ранжирует базу дач, генерирует персонализированный ответ и показывает подходящие карточки.
- Блок **"Найдите дачу на свой вкус"** с кнопкой **"Смотреть дачи"**, переводящей в каталог.
- Топ популярных дач сезона и блок преимуществ сервиса.

---

### 3. Каталог, слайдер картинок и отзывы (`data/products.json`)
- База данных в `data/products.json`:
  - `id`: уникальный идентификатор
  - `name`: название дачи
  - `category`: вилла, большая, средняя, маленькая
  - `price`: цена за сутки в $
  - `stars`: рейтинг (звезды 1-5)
  - `location`: точный адрес (например: *Чарвак, ул. Сайхон, дом 14*)
  - `description`: подробное описание
  - `images`: массив из нескольких фотографий
  - `comments`: массив отзывов пользователей
  - `isBooked` и `bookedDaysRemaining`: статус брони
- **Листание картинок прямо в карточке**: кнопки вперед/назад и индикаторы точек позволяют просматривать все фото прямо в каталоге.
- Возможность открыть окно подробностей с увеличенной галереей и формой добавления нового отзыва с оценкой.

---

### 4. Система бронирования
- **Проверка входа**: перед бронированием система требует авторизоваться (логин или регистрация).
- **Если дача уже занята**:
  - Карточка не блокирует весь экран.
  - Кнопка "Забронировать" отключается (`disabled`).
  - Сверху карточки показывается статус: **"Дача забронирована: осталось X дн. до освобождения"**.
- **Калькулятор дней**:
  - 1 день ($500), 2 дня ($1000 - 2x) и так далее до 7 дней.
  - Кнопка **"Больше дней..."** раскрывает поле ручного ввода любого количества суток с мгновенным умножением суммы.
- **Страница оформления заказа (`/checkout`)**:
  - **Скрыта из навигации**.
  - Поля: **Введите ваше имя**, **Введите свой номер телефона**, пожелания.
  - При подтверждении бронирования:
    1. Заявка отправляется в админку в раздел **"Забронированные"**.
    2. Дача блокируется на выбранное количество суток.
    3. Выводится номер подтвержденного заказа.

---

### 5. Панель администратора (`/admin`)
- Доступ **только через секретную кнопку в футере**.
- **Пароль администратора**:
  ```text
  aripovmuhammadsalim!is11&
  ```
- **Защита URL**: попытка зайти напрямую по адресу `/admin` без ввода пароля мгновенно перенаправляет на Главную страницу.
- Возможности админки:
  1. **Все дачи**: просмотр всех активных дач. При клике открывается редактирование (имя, цена, категория, звезды, локация, картинки, описание). Под каждой дачей есть кнопка **"Удалить в корзину"**.
  2. **Добавить дачу**: форма создания новой дачи со всеми характеристиками.
  3. **Удаленные дачи (Корзина)**: список удаленных объектов с кнопкой **"Вернуть дачу"** (восстанавливает ее в каталог).
  4. **Забронированные**: входящие заявки клиентов (имя, номер телефона, дача, количество суток, сумма, дата) с кнопкой **"Освободить дачу"** (снимает бронь).

## 🛠️ Запуск проекта

1. Установите зависимости (если запускаете впервые):
   ```bash
   npm install
   ```

2. Запустите сервер разработки Next.js:
   ```bash
   npm run dev
   ```

3. Откройте в браузере:
   ```text
   http://localhost:3000
   ```
